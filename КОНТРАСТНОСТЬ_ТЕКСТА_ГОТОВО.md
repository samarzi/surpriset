# ✅ Исправление контрастности текста - ГОТОВО

## 📋 Задача
Установить четкие правила для цветовой схемы текста и элементов:
1. Заголовки, надписи и элементы по умолчанию → **белые**
2. Кнопки с бирюзовой заливкой → текст и элементы **черные**
3. Кнопки без заливки (outline) → текст и элементы **белые**

## ✅ Выполнено

### 1. Глобальные CSS правила
Добавлены 10 комплексных правил в `src/index.css`:

#### Правило 1: Текст по умолчанию
```css
.dark h1, .dark h2, .dark h3, .dark h4, .dark h5, .dark h6,
.dark p, .dark span, .dark label, .dark div {
  color: #ffffff !important;
}
```

#### Правило 2: Кнопки с заливкой
```css
button[class*="bg-primary"],
button[class*="bg-cyan"],
button[class*="bg-teal"] {
  color: #000000 !important;
}
```

#### Правило 3: Кнопки outline
```css
.dark button[variant="outline"],
.dark button[class*="outline"] {
  color: #ffffff !important;
}
```
