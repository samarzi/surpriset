# Удаление увеличения кнопок при нажатии ✅

## Выполненные изменения

### Убрано увеличение размера кнопок при нажатии (active)

Удалены все `scale()` трансформации из следующих элементов при нажатии:

#### `src/index.css`:
1. `.btn-catalog-premium:active` - убран `scale(0.98)`
   - Было: `transform: translateY(-1px) scale(0.98) !important;`
   - Стало: `transform: translateY(-1px) !important;`

2. `.group:active` - убран `scale(0.98)`
   - Было: `transform: scale(0.98);`
   - Стало: `transform: none;`

3. `.mobile-back-button:active` - убран `scale(0.98)`
   - Было: `transform: translateY(0) scale(0.98);`
   - Стало: `transform: translateY(0);`

4. `.mobile-tap-animation:active` - убран `scale(0.95)`
   - Было: `transform: scale(0.95);`
   - Стало: `transform: none;`

5. `.enhanced-click:active` - убран `scale(0.96)`
   - Было: `transform: scale(0.96) !important;`
   - Стало: `transform: none !important;`

6. `.important-button:active` - убран `scale(0.94)`
   - Было: `transform: scale(0.94) !important;`
   - Стало: `transform: none !important;`

**Результат**: Кнопки больше НЕ уменьшаются при нажатии, остаются только другие эффекты (затемнение через brightness, тени).
